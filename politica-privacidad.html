2. Datos personales que podemos tratar

Cuando una persona contacta con Taxi Vilches por teléfono, WhatsApp o correo electrónico, podemos tratar los datos que facilite voluntariamente y que sean necesarios para atender su solicitud.

Estos datos pueden incluir:

  • Nombre y apellidos.
  • Número de teléfono.
  • Dirección o punto de recogida.
  • Destino del trayecto.
  • Fecha y hora del servicio.
  • Información incluida en los mensajes o consultas.

Se recomienda no enviar información especialmente sensible que no sea necesaria para organizar el transporte.

3. Finalidad y base jurídica

Los datos personales se tratarán para las siguientes finalidades:

  • Atender consultas y solicitudes de información.
  • Informar sobre disponibilidad y precios.
  • Gestionar reservas y prestar servicios de taxi.
  • Atender incidencias, reclamaciones y obligaciones legales.

Las bases jurídicas aplicables podrán ser la aplicación de medidas precontractuales o la ejecución de un contrato (artículo 6.1.b del RGPD), el cumplimiento de obligaciones legales (artículo 6.1.c) y, cuando corresponda, el interés legítimo relacionado con la defensa de reclamaciones.

4. Carácter obligatorio de los datos

Facilitar los datos es voluntario. Sin embargo, si no se proporcionan los datos imprescindibles para atender una consulta o gestionar un trayecto, puede que no sea posible prestar el servicio.

5. Conservación de los datos

Los datos se conservarán durante el tiempo necesario para atender la consulta o prestar el servicio. Posteriormente podrán mantenerse bloqueados durante los plazos exigidos por la normativa fiscal, contable, administrativa o de transporte, así como durante los plazos de prescripción de posibles responsabilidades.

Una vez transcurridos dichos plazos, se procederá a su supresión segura.

6. Destinatarios de los datos

Los datos no se venden ni se ceden a terceros para que realicen publicidad propia.

Podrán acceder a ellos proveedores que resulten necesarios para la actividad, como servicios de correo electrónico, alojamiento web o mensajería, así como administraciones públicas y autoridades cuando exista una obligación legal.

Si el usuario contacta mediante WhatsApp, el uso de dicho servicio también queda sujeto a las condiciones y política de privacidad de WhatsApp/Meta.

7. Derechos de las personas

El usuario puede ejercer los derechos de:

  • Acceso a sus datos personales.
  • Rectificación de datos inexactos.
  • Supresión de sus datos cuando proceda.
  • Oposición al tratamiento.
  • Limitación del tratamiento.
  • Portabilidad, cuando sea aplicable.

Para ejercer estos derechos puede escribir a apellizcos@gmail.com, indicando su solicitud y aportando la información necesaria para localizarla.

Solo se solicitará información adicional para verificar la identidad cuando existan dudas razonables. No es necesario adjuntar automáticamente una copia del DNI.

También puede presentar una reclamación ante la Agencia Española de Protección de Datos.

8. Seguridad

Se aplicarán medidas técnicas y organizativas apropiadas para proteger los datos personales frente a pérdida, alteración, acceso o divulgación no autorizados, teniendo en cuenta la naturaleza de los datos y los riesgos del tratamiento.

9. Menores

La web no está dirigida específicamente a menores. Cuando una persona adulta solicite un trayecto para un menor, deberá facilitar únicamente los datos necesarios para organizar el servicio y contar con legitimación para hacerlo.

10. Cambios en esta política

Esta política podrá actualizarse cuando cambien la normativa, los servicios, los canales de contacto o las herramientas utilizadas. La versión vigente será la publicada en esta página.
